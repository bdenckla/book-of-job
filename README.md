[MAM-basics](https://bdenckla.github.io/MAM-basics/book-of-job/) on 2026-09-03.

after the site prefix.

reach, including posts and sent email. There is no enumerable list of those
citations. The [issue tracker](https://github.com/bdenckla/book-of-job/issues)
and the pre-evacuation history remain here; the data and code now live in
MAM-basics.
